# Support

## Getting Help

- **Docs:** start with [README.md](README.md) — setup, tool catalog, embed/raw API, and project structure
- **Contributing:** see [CONTRIBUTING.md](CONTRIBUTING.md) for local setup and the 5-step "add a new tool" checklist
- **Changelog:** [public/CHANGELOG.md](public/CHANGELOG.md) or https://utility.rajlabs.in/changelog
- **Live site:** https://utility.rajlabs.in

## Asking Questions

- **Bug reports & tool requests:** open a GitHub Issue using the templates (Bug Report / Feature Request) — see `.github/ISSUE_TEMPLATE/`
- **Q&A / ideas:** open a GitHub Discussion (if enabled) or an issue with the `question` label
- **Email:** raj@rajlabs.in (for private or security matters — see [SECURITY.md](SECURITY.md) for vulnerabilities)

When asking for help, include:

- The tool route (e.g., `/qr-code-generator?data=hello&raw=image`)
- Browser + OS + app version (see footer / `public/CHANGELOG.md`)
- Steps to reproduce and what you expected vs what happened
- Console errors / screenshots if relevant

## Response Times

This is a community-maintained project. We aim to:

- Triage new issues within **3 business days**
- Review PRs within **5 business days**
- Respond to security reports within **48 hours** (see [SECURITY.md](SECURITY.md))

## What We Don't Support

- Server-side or self-hosted deployments beyond Firebase Hosting (you're free to fork and deploy elsewhere under GPL-3.0)
- Proprietary re-licensing without discussion — open an issue first
- Debugging user-provided private data — please redact sensitive content from reports
